# Rubik Clock

A Rubik Clock puzzle application developed using Qt as a university project.

## About

This was a university task. The most interesting part is that it can't actually be solved like an actual Rubik Clock, because the specification is wrong (or I didn't understand it). It's just a bunch of clock widgets and buttons.
Somehow this was the best university project I found to upload here.

## Technologies

- C++
- Qt

This project was created as a university assignment.
